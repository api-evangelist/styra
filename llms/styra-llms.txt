# Styra (Open Policy Agent / Enterprise OPA)

> Styra is the company that created Open Policy Agent (OPA), the CNCF-graduated policy engine, and commercialized it as Enterprise OPA and Styra DAS (Declarative Authorization Service) for authorization and policy-as-code. Styra was acquired by Akamai in December 2024; the styra.com and docs.styra.com web properties no longer resolve, but the open-source technical surface — GitHub, published SDKs, the OpenAPI spec, and gRPC protobufs — remains active. This llms.txt was generated by the API Evangelist enrichment pipeline from repository artifacts.

## APIs

- [Enterprise OPA / OPA REST API (OpenAPI 3.0.3)](openapi/styra-enterprise-opa-openapi.yaml): Execute policy decisions, batch decisions, partial evaluation / data filtering (UCAST + SQL), and health checks. HTTP bearer-token auth.
- [OPA REST API reference (canonical, live)](https://www.openpolicyagent.org/docs/rest-api)
